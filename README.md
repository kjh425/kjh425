# 👨‍💻 Kim Jun Han's GitHub

안녕하세요.  
**Java / Spring 기반 백엔드 개발을 중심으로, 운영 환경에서 발생하는 문제를 끝까지 해결하는 개발자 김준한**입니다.

저는 단순히 기능을 구현하는 것보다,  
**실제 서비스가 안정적으로 운영되기 위해 필요한 개발, 배포, 보안, 장애 대응까지 함께 고민하는 개발자**를 지향합니다.

2년 이상의 실무 경험을 바탕으로  
공공기관 홈페이지, 복지몰, 모바일 앱, 관리자 시스템 등 다양한 서비스를 운영하며  
**Java, Spring, Spring Boot, Oracle, PostgreSQL, React, React Native, AWS, Docker, Jenkins, GitLab** 등을 활용해왔습니다.

특히 실서비스 운영 과정에서 발생하는  
**성능 이슈, 보안 취약점, 웹 접근성 개선, 배포 자동화, 서버 장애 분석, 대량 데이터 처리 문제**를 직접 다루며  
개발 이후의 운영 안정성까지 고려하는 경험을 쌓아왔습니다.

현재는 **Java / Spring Boot 기반 백엔드 개발 역량**을 중심으로 성장하고 있으며,  
서비스 전체 흐름을 이해하기 위해 프론트엔드, 모바일, 인프라 영역까지 폭넓게 학습하고 적용하고 있습니다.

## 🛠️ Development Focus

저는 현재 **Java / Spring Boot 기반 백엔드 개발 역량**을 가장 중점적으로 강화하고 있습니다.

단순히 API를 만드는 것에서 끝나는 것이 아니라,  
서비스가 실제 운영 환경에서 안정적으로 동작하기 위해 필요한  
**인증, 보안, 데이터 처리, 배포 자동화, 로그 분석, 장애 대응**까지 함께 고려하는 개발자가 되고자 합니다.

또한 React와 React Native를 함께 다루며  
백엔드 API가 실제 사용자 화면에서 어떻게 사용되는지 이해하고,  
프론트엔드와 모바일 환경까지 고려한 실용적인 개발을 지향합니다.
