Java · Spring 기반 백엔드 개발자 김준한입니다.

기능 구현에서 끝내지 않고, 서비스가 실제 운영 환경에서 안정적으로 돌아가기까지 — 개발 · 배포 · 보안 · 장애 대응을 함께 고민합니다.

3년차 개발자로 공공기관 홈페이지, 복지몰, 모바일 앱, 관리자 시스템 등 다양한 실서비스를 운영하며 성능 개선, 보안 취약점 조치, 웹 접근성, 배포 자동화, 장애 분석, 대량 데이터 처리를 직접 다뤄왔습니다.

현재는 Java / Spring Boot 백엔드 역량을 중심으로 성장하면서, 서비스 전체 흐름을 이해하기 위해 프론트엔드 · 모바일 · 인프라까지 폭넓게 다루고 있습니다.
